# Mobile SEO Auditor and Responsive Design Validator

[![Mobile SEO Auditor](https://img.shields.io/badge/TAVARDT-Mobile%20SEO-5b3cf5.svg)](https://tools.tavardt.com/nz/mobile-seo-checker/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Independent verification of viewport meta tags, tap responsiveness, and mobile layouts.

Developed and maintained by the software architecture practice at **TAVARDT**.

***

## Mobile SEO Verification Highlights

* **Viewport Configuration Validation**: Assurance of proper viewport definitions for mobile device rendering.
* **Layout Adaptability Inspection**: Detection of horizontal scroll triggers caused by unresponsive elements.
* **Touch Target Compliance**: Ensuring touchpoints meet minimum ergonomic standards for touchscreens.
* **Font Legibility Assessment**: Verifying that typography scales clearly on small viewports.
* **Mobile SEO Health Score**: Quantitative 0 to 100 score highlighting technical issues.

***

## Installation and Execution

Compatible with Python 3.8 and above without extra packages.

```bash
git clone https://github.com/TAVARDT-New-Zealand/mobile-seo-tester-nz.git
cd mobile-seo-tester-nz
python mobile_seo_tester.py https://enterprise.co.nz
```

Run in JSON mode for CI/CD pipeline automation:

```bash
python mobile_seo_tester.py https://enterprise.co.nz -json
```
